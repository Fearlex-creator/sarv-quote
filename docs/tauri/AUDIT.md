# Tauri interface audit and implementation checkpoint

The product has one Tauri 2 / React frontend and one Rust accounting backend. The GTK4/libadwaita application, duplicate shells and experimental second ledger have been removed. SQLite schema 7, immutable posted records, optimistic generations, exact integer IRR money, opening controls, purchase allocations and goods sales remain intact. The Rust engine and CLI are headless by default; `pdf-export` optionally enables existing PDF rendering. On Linux only the Tauri window requires GTK3/WebKitGTK platform libraries.

Existing capabilities: quotation catalogs/customers/approval/export, core company/chart/fiscal setup, typed openings/CSV staging, manual journals/reversals/period locks/trial balance, purchase orders/receipts/bills/returns, stock transfers, goods sales drafts/orders/paired delivery-invoice/returns.

Missing backend capabilities: service invoicing, payment allocation/refunds, bank statement import/matching/reconciliation, expense receipts/attachments, multiuser authorization, projects/approvals, statutory integrations. Unsupported workflows must be disclosed, never mapped to fictional paid/reconciled states. A local actor is an audit label, not authentication.

New interface inventory: shared shell/sidebar/command palette/theme/density/RTL, overview with backend position and real activity, company setup and explicit zero or CSV opening, operational customers/vendors/items/units/warehouses, durable goods order editor, order delivery/invoice review, partial purchases receipt/bill review, original-cost customer/supplier returns, warehouse transfers, journals/accounts/ledger/period locking, backend P&L/trial/control reconciliation and CSV export, settings. Quotation and custom-chart editors have not yet been connected to React; their accounting APIs and persisted records remain available in Rust. Native Tauri IPC, goods posting, CSV dialogs and window lifecycle pass isolated Linux checks; see DELIVERED.md.

Design: user palette and scales take precedence over generated concept details. Concept `/workspace/generated_images/exec-535f2e81-1817-4d2d-ba07-7846594d9e79.png` defines shell composition and empty overview; reduce generated heading size to prescribed 24px, use exact 232/56px sidebar/toolbar, remove generated active indicator and unsupported invoice/payment wording. Table and form downstream screens extend the same native components. The generated image is a design reference, not data or the application.

Verification checklist: frontend types/lint/build; Tauri check/build; unchanged default-feature Rust suite and strict Clippy; new IPC string/integrity/isolation tests; browser QA using an explicitly gated loopback Rust adapter over a separate synthetic profile; screenshot inspection at required desktop sizes, dark/RTL; native Tauri smoke with temporary read-only WebKit helper mappings. No claimed release readiness before these gates and feature limitations are reported.
