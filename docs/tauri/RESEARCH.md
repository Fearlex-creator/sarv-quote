# Focused interaction research — 2026-10-10

Fetch evidence is recorded in `artifacts/tauri-research/fetch.json`. This is a bounded public-document pass, not hands-on authenticated product testing. Stripe Dashboard basics, Things product page, Raycast manual, Xero invoicing, QuickBooks invoicing and FreshBooks invoice pages were retrieved. Linear's guessed command-menu URL returned 404; Craft, Zoho and Sage returned 403. The existing official workflow notes under `requirements/research/official-workflows.md` retain their dated scope and must not be presented as newly observed. No review statistics or sourced user complaints are claimed.

Adaptations: Stripe's searchable, inspectable financial records → totals with a stated source/period and ledger drill-down. Things' restrained task grouping → setup/action queues and measured hierarchy. Raycast's keyboard command approach → Ctrl/Cmd+K navigation/action palette with visible shortcut hints. Xero/QuickBooks/FreshBooks document workflows → clear separation of editable draft, recorded order, delivered invoice and outstanding receivable. The existing goods kernel requires paired delivery and invoice; keep that accounting meaning explicit.

Design interpretation (not user feedback): colorful metrics can hide operational work; a sparse table may obscure status; nested panels impede scanning; accounting controls should reveal their financial effect before a commit. Avoid pretending missing banking/payment services are functional. Preserve typed source links and exact money over visual shortcuts. Use a warm-neutral palette, one quiet green action color, compact tables, stable record identities, clear errors, native save dialogs, and strong keyboard focus.
