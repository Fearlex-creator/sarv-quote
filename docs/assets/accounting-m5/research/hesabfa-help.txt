مرورگر پیشنهادی
حسابفا یک نرم‌افزار حسابداری آنلاین و تحت وب است که امکان دسترسی به اطلاعات را از طریق هر دستگاه متصل به اینترنت فراهم می‌کند. برای استفاده از حسابفا، نیازی به
نصب نرم‌افزار
نیست و تنها کافی است از یک مرورگر به‌روز استفاده کنید.
حسابفا با مرورگرهای به‌روز، مانند موارد زیر، اجرا می‌شود:
• Google Chrome
• Microsoft Edge
• Mozilla Firefox
• Safari 8 و نسخه‌های بالاتر
• Internet Explorer
برای بهره‌مندی از تمام امکانات حسابفا، پیشنهاد می‌شود از نسخه‌های به‌روز مرورگرهایی مانند
Google Chrome
،
Microsoft Edge
یا
Mozilla Firefox
استفاده کنید.
توجه داشته باشید که استفاده از حسابفا در
ویندوز ۷
ممکن است با مشکلاتی همراه باشد، زیرا این سیستم‌عامل دیگر به‌روزرسانی‌های امنیتی و عملکردی دریافت نمی‌کند. به همین دلیل، توصیه می‌شود از آخرین نسخه ویندوز یا سایر سیستم‌عامل‌های پشتیبانی‌شده استفاده کنید.
